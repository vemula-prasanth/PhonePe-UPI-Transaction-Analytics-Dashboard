# 📌 Project Overview

The **PhonePe UPI Transaction Analytics Dashboard** is an end-to-end Microsoft Excel Business Intelligence project designed to analyze UPI transaction data and provide actionable insights into customer payment behavior, transaction performance, banking trends, merchant activity, and fraud monitoring.

This dashboard enables users to interactively explore data using slicers and dynamic charts. It allows stakeholders to monitor transaction volume, transaction value, cashback distribution, success rate, fraud detection, bank-wise performance, state-wise analysis, and hourly transaction trends through a clean and professional dashboard.

The primary objective of this project is to transform raw UPI transaction data into meaningful business insights that support data-driven decision-making.

# 📈 Key Performance Indicators (KPIs)

Represents the percentage of successful UPI transactions.

# 📊 Business Insights

The dashboard reveals several meaningful business insights:

✔ PhonePe dominates the UPI market with the highest transaction share.

✔ More than 90% of transactions are successfully completed, indicating strong platform reliability.

✔ Cashback campaigns contribute significantly to customer engagement.

✔ Evening hours generate the highest transaction volume.

✔ Metro cities contribute the largest transaction value.

✔ Shopping and Bill Payments account for a significant share of digital transactions.

✔ Leading banks process substantially higher transaction amounts than smaller banks.

✔ Fraudulent transactions represent only a small percentage of total transactions but require continuous monitoring.

✔ Heatmap analysis helps identify customer transaction patterns.

✔ Merchant category analysis provides valuable information about customer spending behavior.
